OpenPatrimoine is a desktop application for landlords who want to stay in control of their real estate portfolio **without subscriptions, without the cloud, without compromising on privacy**. All your data stays on your machine.

## What it does

### Your properties, at a glance
Centralize all your properties — apartments, houses, parking spaces, commercial units. Each property exposes real-time statistics: occupancy rate, gross yield, projected annual revenue.

### Tenants & leases
Manage the complete history of your tenants with lease dates, rent amounts including charges, and the status of each contract. Generate **rent receipts as PDF** in one click, directly from the app.

### Rent tracking
Visualize the payment status of every rent month by month — paid, pending, late. Automatically generate rent entries for an entire month across all your tenants. Send payment reminders via a pre-written formal letter, ready to copy.

### Built-in accounting
Log all your income and expenses per property: rent collected, repair work, building charges, property taxes, loan interest. Export your bookkeeping as **CSV** for your accountant or tax return.

### Tracking & analytics
Visualize the monthly evolution of your income and expenses through clear charts. Identify your best-yielding properties, underperforming assets, and at-risk tenants.

### Legal documents
Generate common landlord documents directly from the app: rent receipts and payment reminder letters.

## Installation

### Pre-built

Download the latest installer from [Releases](#):

- **Windows** → `OpenPatrimoine-x.x.x-setup.exe`
- **macOS** → `OpenPatrimoine-x.x.x.dmg`
- **Linux** → `.AppImage`, `.deb`, or `.snap`

### From source

```bash
# Clone the repository
git clone https://github.com/HugoHaymann/openpatrimoine.git
cd openpatrimoine

# Install dependencies
npm install

# Run in development mode
npm run dev

# Build
npm run build:win    # Windows
npm run build:mac    # macOS
npm run build:linux  # Linux
```

## Tech stack

Built with modern technologies, no compromises:

- **Electron 39** — native cross-platform desktop app
- **React 19 + TypeScript** — reactive, fully typed UI
- **Vite (electron-vite)** — lightning-fast builds
- **Tailwind CSS v4 + shadcn/ui** — consistent design system, dark theme
- **TanStack Query v5** — seamless state and data synchronization
- **Local JSON storage** — no external database, no server

---

## Privacy

OpenPatrimoine collects no data whatsoever. Zero telemetry. Zero analytics. Zero network calls. Your properties, your tenants, your finances — everything stays on your local disk, in your user folder.
